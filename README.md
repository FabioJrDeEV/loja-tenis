# Loja Sapatos 👟

Uma plataforma de e-commerce moderna e elegante dedicada à venda de calçados de alta qualidade. Desenvolvida com as tecnologias mais recentes do ecossistema React/Next.js, focada em performance, design responsivo e experiência do usuário.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- **Next.js 16**: Framework React com suporte a App Router para rotas otimizadas e renderização híbrida.
- **TypeScript**: Tipagem estática para maior segurança e produtividade no desenvolvimento.
- **Tailwind CSS**: Framework CSS utilitário para um design moderno, rápido e totalmente responsivo.
- **Lucide React**: Biblioteca de ícones leves e elegantes.
- **React Hook Form & Zod**: Gerenciamento de formulários e validação de dados robusta.
- **Context API**: Gerenciamento de estado global (ex: Carrinho de Compras).

## ✨ Funcionalidades

- [x] **Design Responsivo**: Experiência otimizada para Desktop, Tablets e Smartphones.
- [x] **Navegação Fluida**: Rotas organizadas para categorias Masculino, Feminino e Novidades.
- [x] **Carrossel de Destaques**: Exibição dinâmica dos principais produtos na Home.
- [x] **Grade de Produtos**: Visualização clara e organizada do catálogo.
- [x] **Carrinho de Compras**: Drawer interativo para gerenciamento de itens selecionados.
- [x] **Autenticação**: Páginas de Login e Cadastro com validação de formulários em tempo real.
- [x] **Página de Contato**: Canal direto de comunicação para suporte ao cliente.

## 📂 Estrutura do Projeto

```text
src/
├── app/              # Rotas, páginas e layouts (App Router)
├── components/       # Componentes de interface reutilizáveis
├── context/          # Contextos do React (Estado Global)
├── data/             # Dados estáticos e mockups (Produtos)
├── schemas/          # Schemas de validação Zod
└── globals.css       # Estilos globais e configurações Tailwind
```

## 🛠️ Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/loja-sapatos.git
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   O projeto estará disponível em `http://localhost:3000`.

## 📦 Scripts Disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Cria a versão de produção da aplicação.
- `npm run start`: Inicia o servidor de produção.
- `npm run lint`: Executa a verificação do Linter.
